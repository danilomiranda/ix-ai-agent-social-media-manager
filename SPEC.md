## 1. System Overview

### Architecture

```
┌─────────────────────────────────────────────────────────┐
│  INGESTION                                               │
│  file watcher (input/) ──or── POST /ingest              │
└────────────────────────┬────────────────────────────────┘
                         │ creates Source + Job → enqueues transcribe
┌────────────────────────▼────────────────────────────────┐
│  ORCHESTRATION (Node.js / Fastify + BullMQ)             │
│  5 queues: transcribe → select → reframe → edit → publish│
│  API: /ingest  /clips  /jobs  /health                   │
└──────┬──────────┬──────────┬──────────┬──────────┬──────┘
       │          │          │          │          │
   python3    Claude API  python3   remotion    Late API
  transcriber  (agents)  clip_ext   render    + Zernio
       │          │          │          │          │
   .srt +      Clip      9:16 mp4   edited    published
  words.json  records     + json     mp4      post
┌──────────────────────────────────────────────────────────┐
│  DATA (Prisma SQLite → Postgres)                        │
│  Source · Job · Clip · Post · Lead                      │
└──────────────────────────────────────────────────────────┘
```

### Layer Ownership

| Layer | Owns | Never Touches |
|-------|------|---------------|
| API routes (`src/api/`) | Request validation, HTTP responses, Source/Job creation | Worker logic, Python execution |
| Workers (`src/workers/`) | Job status updates, subprocess spawning, queue fan-out | HTTP request/response, direct DB schema changes |
| Agents (`src/agents/`) | Claude API calls, JSON schema validation | File I/O, subprocess spawning |
| Python CLI | File I/O, CV/ML processing, transcript output | Database, Redis, HTTP |
| Remotion (`remotion/`) | Video composition, rendering | Database, API calls, Python |
| Skills (`.claude/skills/`) | Claude Code sessions, manual orchestration | Production DB writes, worker queues |

### Pipeline Flow

```
Video in input/ or POST /ingest
  → [transcribe] python -m transcriber → transcript.srt + transcript.words.json
  → [select] ViralDetectorAgent → Clip records with scores         [STUB]
  → user approval: POST /clips/:id/approve
  → [reframe] python -m clip_extractor batch → reframed-9x16.mp4
  → [edit] VideoEditorAgent → .tsx → npx remotion render           [STUB]
  → [publish] Zernio upload + Late API → Post record               [STUB]
```

## 2. Database Schema

> **Boundary:** Workers UPDATE existing records. Routes CREATE Source and Job. Agents CREATE Clip records. Never drop or alter columns without a migration.

### Source

| Field | Type | Values / Notes |
|-------|------|----------------|
| id | String (cuid) | PK |
| type | String | `youtube_video` \| `local_file` \| `podcast` |
| url | String? | YouTube URL |
| filePath | String? | Absolute path to local file |
| title | String? | Derived from filename or user input |
| durationSec | Float? | Optional, set post-transcription |
| initiative | String | `social_engine` \| `dark_channel` \| `consulting` \| `music` |
| status | String | `pending` \| `processing` \| `done` \| `failed` |
| createdAt | DateTime | Auto |

### Job

| Field | Type | Values / Notes |
|-------|------|----------------|
| id | String (cuid) | PK |
| sourceId | String | FK → Source |
| type | String | `transcribe` \| `select` \| `reframe` \| `edit` \| `publish` |
| status | String | `queued` → `running` → `done` \| `failed` |
| input | String? | JSON blob — job-specific input args |
| output | String? | JSON blob — job-specific outputs |
| error | String? | Error message on failure |
| startedAt | DateTime? | Set when worker picks up job |
| completedAt | DateTime? | Set on done or failed |
| createdAt | DateTime | Auto |

### Clip

| Field | Type | Values / Notes |
|-------|------|----------------|
| id | String (cuid) | PK |
| sourceId | String | FK → Source |
| title | String? | Generated by ClipSelectorAgent |
| startSec | Float? | Clip start timestamp in source video |
| endSec | Float? | Clip end timestamp in source video |
| hookStrength | Int? | Score 0–100 |
| valueDelivery | Int? | Score 0–100 |
| clarity | Int? | Score 0–100 |
| shareability | Int? | Score 0–100 |
| completeness | Int? | Score 0–100 |
| totalScore | Int? | Sum of category scores |
| category | String? | Content category label |
| filePath | String? | Absolute path to reframed-9x16.mp4 |
| editedPath | String? | Absolute path to Remotion-rendered output |
| transcriptExcerpt | String? | Hook text for preview |
| approved | Boolean | Default false. Set true via POST /clips/:id/approve |
| createdAt | DateTime | Auto |

**Behavior:** `filePath` must exist on disk before `POST /clips/:id/approve` can proceed. Returns 422 otherwise.

### Post

| Field | Type | Values / Notes |
|-------|------|----------------|
| id | String (cuid) | PK |
| clipId | String | FK → Clip |
| platform | String | `tiktok` \| `instagram` \| `youtube` \| `linkedin` \| `twitter` \| etc. |
| latePostId | String? | Late API post ID after publish |
| title | String? | Platform-specific title |
| caption | String? | Platform-specific caption |
| hashtags | String? | JSON array, e.g. `["#ai","#shorts"]` |
| status | String? | `draft` \| `scheduled` \| `published` \| `failed` |
| publishedAt | DateTime? | Set on successful publish |
| views/likes/shares/comments | Int | Analytics, default 0 |
| createdAt | DateTime | Auto |

### Lead

| Field | Type | Values / Notes |
|-------|------|----------------|
| id | String (cuid) | PK |
| source | String? | `youtube_comment` \| `linkedin_dm` \| `email` |
| initiative | String? | `consulting` \| `music` |
| name / contact / content | String? | Lead details |
| score | Int? | Lead quality score |
| status | String | `new` \| `contacted` \| `qualified` \| `closed` |
| createdAt | DateTime | Auto |

## 3. API Routes

> **Boundary:** Routes validate input and return HTTP. They CREATE Source + Job records only. They never spawn subprocesses or call Python directly.

### POST /ingest

**Purpose:** Start the pipeline for a video.

**Request body:**
```json
{ "filePath": "/abs/path/video.mp4", "url": "https://...", "title": "optional", "initiative": "social_engine" }
```

**Validation:**
- `filePath` or `url` required (400 if both missing)
- `initiative` defaults to `social_engine`
- Output dir computed as `output/clips/YYYY-MM-DD-<slugified-title>/`

**Side effects:**
1. Creates `Source` record
2. Creates `Job` record (type: `transcribe`, status: `queued`)
3. Enqueues to `queues.transcribe` with `{ jobId, sourceId, sourcePath, outputDir }`

**Response:** `201 { sourceId, jobId }`

**Security:** `filePath` is passed to the transcribe worker. See Section 7 for path validation rules.

---

### GET /health

**Response:** `200 { ok: true }`

---

### GET /clips/pending

**Purpose:** List all unapproved clips sorted by score.

**Response:** Array of Clip records (includes `source.title`, `source.initiative`), ordered by `totalScore DESC, createdAt DESC`.

---

### GET /clips/:id

**Response:** Single Clip with `posts[]` and full `source` included. 404 if not found.

---

### POST /clips/:id/approve

**Purpose:** Approve clip and trigger edit pipeline.

**Request body:** `{ "platforms": ["tiktok","instagram"], "caption": "optional" }`

**Validation:**
- Clip must exist (404 if not)
- `clip.filePath` must be set (422 if null — reframe hasn't run yet)

**Side effects:**
1. Sets `clip.approved = true`
2. Enqueues to `queues.edit` with `{ clipId, reframedPath, outputDir, platforms, caption }`

**Response:** `200 { ok: true, message: "Clip <id> approved — edit job enqueued" }`

---

### POST /clips/:id/reject

**Side effects:** Sets `clip.approved = false`.

**Response:** `200 { ok: true }`

---

### GET /jobs/:id

**Response:** Single Job record. 404 if not found.

---

### GET /jobs?sourceId=

**Response:** Last 50 Job records for given source, ordered `createdAt DESC`.

## 4. Workers

> **Boundary:** Workers update Job/Clip/Post status and enqueue next jobs. They never handle HTTP. All subprocess calls must use the `spawnAsync()` helper pattern — never `exec()` or shell interpolation.

### transcribe.worker `[LIVE]`

| Property | Value |
|----------|-------|
| Queue | `transcribe` |
| Concurrency | 2 |
| Subprocess | `python3 -m transcriber --video <path> --output <dir>` |
| CWD | `python/` |

**Job input:** `{ jobId, sourceId, sourcePath, outputDir }`

**Sequence:**
1. Update Job: `running`, set `startedAt`
2. Spawn transcriber
3. Update Job: `done`, set `output: { outputDir }`, `completedAt`
4. Enqueue `select` with `{ sourceId, sourcePath, transcriptPath, wordsJsonPath, outputDir }`

**On failure:** Update Job: `failed`, set `error`, `completedAt`

**Outputs produced:** `outputDir/transcript.srt`, `outputDir/transcript.words.json`

---

### select.worker `[STUB]`

| Property | Value |
|----------|-------|
| Queue | `select` |
| Concurrency | 2 |
| Target | ViralDetectorAgent + ClipSelectorAgent (Week 2) |

**Job input:** `{ sourceId, sourcePath, transcriptPath, wordsJsonPath, outputDir }`

**Current behavior:** Logs stub warning, takes no action. User must manually create clips via API or skill.

**When implemented (Week 2):**
1. Run deterministic prescreener (density, hooks, sentiment) on transcript segments
2. Send top 20 to Claude API (`runAgent<ScoredClip[]>`)
3. Resolve timestamps via fuzzy-match → exact SRT times
4. CREATE Clip records with scores, startSec, endSec, transcriptExcerpt
5. Enqueue `reframe` per clip

**Must NOT:** Auto-approve clips. Human approval is always required.

---

### reframe.worker `[LIVE]`

| Property | Value |
|----------|-------|
| Queue | `reframe` |
| Concurrency | 1 (GPU/CPU intensive) |
| Subprocess | `python3 -m clip_extractor batch --video <src> --clips <json> --output <dir>` |
| CWD | `tools/` |

**Job input:** `{ clipId, sourcePath, clipDefinitionsPath, outputDir }`

**Sequence:**
1. Spawn clip_extractor batch
2. Update `Clip.filePath = outputDir/reframed-9x16.mp4`
3. Enqueue `edit` with `{ clipId, reframedPath, outputDir }`

**On failure:** Log error (no Job record — clip reframe is triggered from clip approval, not a Job record currently).

---

### edit.worker `[STUB]`

| Property | Value |
|----------|-------|
| Queue | `edit` |
| Concurrency | 2 |
| Target | VideoEditorAgent → generate .tsx → npx remotion render |

**Job input:** `{ clipId, reframedPath, outputDir, compositionId?, platforms?, caption? }`

**Current behavior:** Returns immediately if `compositionId` missing (stub). If `compositionId` provided, runs `npx remotion render remotion/index.ts <compositionId> <outputPath>`.

**When implemented (Week 2):**
1. Call VideoEditorAgent with transcript excerpt + reframed video path
2. Agent generates Remotion `.tsx` file → write to `remotion/compositions/`
3. Generate word-timing `.ts` data file → `remotion/data/`
4. Run `npx remotion render`
5. Update `Clip.editedPath`
6. Enqueue `publish`

**Output:** `outputDir/edited.mp4`

---

### publish.worker `[STUB]`

| Property | Value |
|----------|-------|
| Queue | `publish` |
| Concurrency | 3 |
| Target | Zernio upload + Late API POST |

**Job input:** `{ clipId, editedPath?, platforms?, caption?, title?, hashtags? }`

**Current behavior:** Creates a `Post` record with `status: draft`. Does NOT call Late API.

**When implemented (Week 3):**
1. Upload `editedPath` to Zernio via `POST /media/presign` → PUT → get `publicUrl`
2. Call CopywriterAgent for platform-specific caption/title/hashtags per platform
3. `POST https://getlate.dev/api/v1/posts` with `platforms[]`, `mediaUrl`, copy
4. Update Post records with `latePostId`, `status: published`, `publishedAt`

**Must NOT:** Publish without an `editedPath` that exists on disk.

## 5. Python CLI Contracts

> **Boundary:** Python tools are black boxes. Node.js calls them via `spawnAsync()`. Never import Python modules from Node. Never call Node from Python.

### python -m transcriber

**CWD:** `python/`

**Command:**
```bash
python3 -m transcriber --video <abs_path> --output <abs_dir> [--language en] [--model large-v3]
```

**Outputs (both required):**
- `<outputDir>/transcript.srt` — SRT subtitle file, max 60 chars/line
- `<outputDir>/transcript.words.json` — Array of `{ word, start, end, score }` objects

**Exit codes:** `0` = success, `1` = video not found or WhisperX not installed

**Dependencies:** `whisperx`, `torch` (GPU preferred, CPU fallback)

---

### python -m clip_extractor reframe

**CWD:** `tools/`

**Command:**
```bash
python3 -m clip_extractor reframe --video <abs_path> --output <abs_dir> --format 9x16
```

**Outputs:**
- `<outputDir>/reframed-9x16.mp4` — Face-tracked vertical reframe

**Formats:** `9x16` (portrait), `1x1` (square), `split` (dual-speaker)

---

### python -m clip_extractor batch

**CWD:** `tools/`

**Command:**
```bash
python3 -m clip_extractor batch --video <abs_path> --clips <abs_json> --output <abs_dir>
```

**clips JSON format:**
```json
[{ "id": "clip1", "start": 12.4, "end": 67.8, "title": "Hook moment" }]
```

**Outputs per clip:** `<outputDir>/<id>/reframed-9x16.mp4` + `<outputDir>/<id>/crop_path.json`

---

### python -m clip_extractor analyze

**Command:**
```bash
python3 -m clip_extractor analyze --video <abs_path> --output <abs_dir>
```

**Outputs:** `<outputDir>/crop_path.json` only (no rendered video). Use for inspection before rendering.

---

### python -m clip_extractor render

**Command:**
```bash
python3 -m clip_extractor render --video <abs_path> --crop-path <json> --output <abs_dir> --format 9x16
```

**Inputs:** Pre-existing `crop_path.json` (from `analyze` command or manually edited)

## 7. Security & Validation Rules

### Path Injection Prevention

**CRITICAL:** User-supplied file paths (`filePath`, `url`) must NEVER be interpolated into shell strings. Always pass as array arguments to `spawnAsync()`.

```typescript
// SAFE — arguments array, no shell interpolation
spawnAsync('python3', ['-m', 'transcriber', '--video', userPath, '--output', outDir], cwd)

// UNSAFE — never do this
exec(`python3 -m transcriber --video ${userPath}`)
```

**Path allowlist (Node workers):**
- `sourcePath` must be an absolute path or a `https://` URL
- `outputDir` must start with `path.resolve('output/')`
- Workers must reject jobs where paths escape the project root

### API Key Handling

- API keys are loaded via `src/config.ts` (Zod-validated at startup)
- Keys are **never** logged, **never** included in HTTP responses, **never** passed to Python subprocesses as CLI args
- If a key is missing, the process exits at startup with a clear error

### Input Validation (API Routes)

| Route | Validation |
|-------|-----------|
| POST /ingest | Require `filePath` or `url`. Reject if both missing (400). `initiative` defaults to `social_engine`. |
| POST /clips/:id/approve | Clip must exist (404). `clip.filePath` must be set (422). |
| POST /clips/:id/reject | Clip must exist (404). |

### Output Directory Rules

- **ALL** generated artifacts go in `output/` organized by type:
  - Clips: `output/clips/YYYY-MM-DD-slug/`
  - Thumbnails: `output/thumbnails/YYYY-MM-DD-slug/`
  - Carousels: `output/carousels/YYYY-MM-DD-slug/`
  - Documents: `output/documents/YYYY-MM-DD-slug/`
  - Posts: `output/posts/YYYY-MM-DD-slug/`
- Never write to `~/Downloads`, `/tmp`, or any path outside the project root

### Job Failure Handling

Every worker must handle failures explicitly:
1. Catch subprocess errors (non-zero exit code)
2. Update Job record: `status: 'failed'`, `error: err.message`, `completedAt: new Date()`
3. Do NOT silently swallow errors or leave jobs in `running` state

### Environment Variables

Required at startup (enforced by `src/config.ts`):
```
ANTHROPIC_API_KEY   — Claude API
ZERNIO_API_KEY      — Late/Zernio media storage
ZERNIO_PROFILE_ID   — Late profile
KIE_API_KEY         — KIE.ai image generation
DATABASE_URL        — Prisma (default: file:./dev.db)
REDIS_URL           — BullMQ (default: redis://localhost:6379)
PORT                — API server (default: 3001)
```
